## Unsupported or needs review

- Artifact_Intake.Detected_Objects — Text holds post-submit labels. Not a column that fills itself.
  - What to do: Keep the AI-filled value out of the automatic form, or add a reviewed post-submit enrichment step before go-live.
- Artifact_Intake.External_Record — Needs a Connection the owner authorizes later. The column stores the external id or display text. The fetch is not generated by the schema step.
  - What to do: Authorize the matching connection during migration where one exists; otherwise keep the external reference as text and complete the lookup after launch.
- Artifact_Intake.Extracted_Terms — Not a column that fills itself. Text stores the Zia result of a post-submit call. The call is not part of this schema step.
  - What to do: Keep the AI-filled value out of the automatic form, or add a reviewed post-submit enrichment step before go-live.
- Artifact_Intake.Forecast — Needs a trained Zia model. No column is generated. Not-yet-tried as a generated field.
  - What to do: Keep the AI-filled value out of the automatic form, or add a reviewed post-submit enrichment step before go-live.
- Artifact_Intake.Old_Crm_Record — Pre-Creator 5 record id (API type 23). Bigint column. The CRM connection is owner-later.
  - What to do: Authorize the matching connection during migration where one exists; otherwise keep the external reference as text and complete the lookup after launch.
- Artifact_Intake.Old_Crm_Reference — Pre-Creator 5 display value (API type 22). Text column. The CRM connection is owner-later and is not created here.
  - What to do: Authorize the matching connection during migration where one exists; otherwise keep the external reference as text and complete the lookup after launch.
- Artifact_Intake.Shelf_Code — Creator builds the code from static text plus other fields. The column stores that payload. The renderer is not a Data Store type. At most two per form in Creator; this step does not enforce the cap beyond reporting the field.
  - What to do: Enter or paste the code value into the generated text field, or add a reviewed scanning flow if the device workflow is required.
- Artifact_Intake.Site_Location — Not a Creator field type. Latitude and longitude exist only inside Address (and Added/Modified Location). No geo column is invented for this token. If a source still says geolocation, it is reported unsupported.
  - What to do: Capture the needed address/location in the supported address or location fields instead of a separate geo field.
- Artifact_Intake.Text_From_Image — Text holds a post-submit Zia OCR result. Depends on the image living in Stratus. Not self-filling.
  - What to do: Keep the AI-filled value out of the automatic form, or add a reviewed post-submit enrichment step before go-live.
- Artifact_Intake.Tone_Result — Same as keyword extraction: text holds a post-submit Zia result. Not self-filling.
  - What to do: Keep the AI-filled value out of the automatic form, or add a reviewed post-submit enrichment step before go-live.
