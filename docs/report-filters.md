# Report filters requiring manual translation

The repair procedure for `report-criteria` and `Filter not migrated` TODOs ships
with the plugin:
[`plugin/skills/c2c-ui/references/report-filters.md`](../plugin/skills/c2c-ui/references/report-filters.md).

The report and filter IR retain the original criteria (see [IR v1](ir-v1.md)).
Creator variables and `thisapp` calls are listed with their Deluge documentation
sources in [the builtin catalogue](deluge-builtins.json).
[Record access rules](security-model.md) must still hold after a repair.
