# c2c 1.0 Release Notes

`c2c` converts Creator exports into Catalyst project source: schema definitions, translated Deluge workflows, a React UI, and deployment-oriented project files. The early planning and generation stages run offline (`docs/guide/03-the-journey.md`); `docs/guide/04-your-five-steps.md` lists the steps that ask for confirmation.

## What is included

- Schema and field mapping, including forms, subforms, lookups, decimal shadow columns, and system fields (`docs/schema-mapping.md`, `docs/precision-mapping.md`).
- Deluge translation to Node.js functions and client handlers (`docs/deploy-functions.md`, `docs/react-target.md`). Server-side Deluge snippets that cannot be translated safely remain manual steps (`docs/ui.md`).
- React UI generation for forms, reports, pages, navigation, and supported snippets (`docs/ui.md`, `docs/react-target.md`).
- Data migration with checkpointed operations and source-ID mapping (`docs/large-data.md`, `packages/data/src/checkpoint-file.ts`).
- Node.js compatibility range `>=20.20 <23`, with Node 20 or 22 launcher gates (`package.json`, `plugin/bin/c2c`).
- Deterministic output tooling and manifests (`docs/determinism-status.md`, `packages/determinism`).

## Security and deployment boundary

Generated-server authorization, URL-scheme restriction and HTML/CSS sanitization are described in `docs/security-model.md`, `docs/report-action-navigation.md` and `docs/ui.md`. This documentation does not record verification against a deployed Catalyst project; review the generated manual steps and test the deployment before exposing it.

## Known gaps

The full list is in `docs/known-gaps.md`. In short:

- Server-side Deluge snippets remain manual steps (`docs/ui.md`, `docs/fill-todos.md`).
- Platform limits that have no generated equivalent are listed construct by construct, with the manual step, in `docs/known-gaps.md` (*Platform limits and their manual steps*): video recording length, image markup, image camera on load, other camera lenses, remote document-store browsing, report `customlayouts` and timeline options, built-in record columns, maps without an address field, custom actions, script and iframe elements, remote CSS backgrounds, embedded forms without a view, click parameters, `openUrl` shapes, and report-view mail attachments.
- Unsupported or dynamic `openUrl` targets and markup the sanitizer drops are reported as manual steps (`docs/report-action-navigation.md`, `docs/ui.md`).
- Unsupported workflow approver forms (form-field, reporting-level) are denied by the endpoint and counted in `migration-report.json` (`approver-field`, `approver-reporting-level`) (`docs/ui.md`).
- Creator placement relative to On Validate is unverified (`docs/ui.md`). Other unverified limits stay marked `[UNVERIFIED]` in the referenced docs.
- Residual TODO counts per app and per kind change with every input; run `c2c analyze` on your own export and read its report instead of relying on a published figure (`docs/determinism-status.md`).
