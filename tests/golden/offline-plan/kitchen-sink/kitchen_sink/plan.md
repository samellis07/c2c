## Field behavior gaps (no silent shim)

- address: 1 field (Guest.Venue_Address) — One column per part. Latitude and longitude are double columns on the address, not a geolocation field (that field type does not exist). No map picker is generated.
- audio: 1 field (Media_Kit.Voice_Note) — Stratus object key plus a player later. No audio recorder is generated by the schema step.
- auto-number: 1 field (Media_Kit.Ticket) — ROWID is not a substitute: it has no prefix, start, or reset. A bigint column plus a generated counter (start index from the .ds) is the plan. Concurrent inserts can collide until an atomic increment is proven, so this stays partial.
- checkbox-multi: 1 field (Guest.Extras) — The .ds token checkboxes is a list, not a boolean. Stored as text holding a JSON list. values = Form.Field is a multi lookup (junction table).
- currency: 2 fields (Gear.Daily_Rate, Booking.Deposit) — Stored as a canonical decimal string in varchar 64, not Double and not bigint minor units. The ISO 4217 code on the field (type = INR) is column metadata, not a cell. Scale is the field decimal places (default 2). ZCQL orders the varchar as text.
- date-time: 2 fields (Session_Log.Logged_On, Booking.Starts_At) — Datetime column. Creator stores the app timezone; Catalyst datetime timezone handling is not the same, so a shim converts. The difference is reported, not ignored.
- decimal: 1 field (Booking.Hours) — Decimal is not a Data Store column type (Text, VarChar, Date, DateTime, Int, Double, Boolean, BigInt, Foreign Key, Encrypted). Stored as a canonical decimal string in varchar 64. Scale is the field decimal places (default 2). Extra fractional digits quantize half-away-from-zero. ZCQL orders the varchar as text.
- email: 1 field (Guest.Contact_Email) — There is no email column (API type email returns PATTERN_NOT_MATCHED). Stored as varchar plus a generated format check. Creator’s exact rule is unpublished, so the check can differ on edge cases.
- encrypted: 1 field (Guest.Access_Code) — Encrypted text. Equality comparisons only; range and partial match are not available. Reported so it is not stored as plain text.
- file-upload: 1 field (Media_Kit.Contract) — The column stores a Stratus object key, not the bytes: uploads/<form>/<field>/<sha256>/<name> from a signed PUT, or migrated/<form>/<field>/<record id>/<name> from the byte mover. Reads are signed GET URLs. Bucket creation and permissions are not done by this step.
- formula: 1 field (Media_Kit.Total_Hours) — The value is computed, not entered. A text column holds the result until expression translation knows the result type. It is not dropped and it is not a ROWID.
- image: 1 field (Media_Kit.Cover) — Stratus object key (same upload, download, and byte-migration path as file upload). Thumbnail, crop, and annotation are not generated.
- lookup-multi: 1 field (Booking.Gear_Refs) — No multi-value foreign key. A junction table holds two ids (this row’s ROWID and the related ROWID), each a foreign key when the target form exists. A missing target is a bigint id and "FK needs console".
- lookup-single: 2 fields (Booking.Room_Ref, Media_Kit.Booking_Ref) — Foreign key is creatable by API: data_type "foreign key" and on_delete "ON-DELETE-SET-NULL" (optional) or "ON-DELETE-CASCADE" (mandatory). ZCQL INNER/LEFT joins need this FK. The parent column is ROWID. A missing target form becomes a bigint id column and the report says "FK needs console". Picklist, radio, and list fields with values = Form.Field use this row (list uses the multi row).
- multi-line: 1 field (Booking.Brief) — Data Store text holds 10,000 characters. A generated length check rejects the rest. Multi-line formula output (up to 65,355) does not fit.
- multi-select: 1 field (Guest.Tags) — No array column. Stored as text holding a JSON list. Criteria do not match list semantics. values = Form.Field on this type is a multi lookup (junction table), not this column.
- percent: 1 field (Booking.Discount) — Creator stores the percentage number, not a fraction of 1. The % sign is display only. Stored as a canonical decimal string in varchar 64 at the field scale (default 2). ZCQL orders the varchar as text.
- phone: 1 field (Guest.Contact_Phone) — There is no phone column. Stored as varchar. Country digit rules are a generated table and can drift from Creator.
- rich-text: 1 field (Media_Kit.Notes) — Text column (10,000) for HTML. The editor widget and sanitizer are not the column. Longer HTML is rejected by a generated check.
- signature: 1 field (Media_Kit.Sign_Off) — Stratus key for a PNG. The pad canvas is uploaded as PNG bytes through the same signed PUT as a file upload.
- subform: 1 field (Booking.Lines) — The .ds token is grid. Every inline subform (nested fields, no values = Form.Field) becomes its own child table with a parent_id foreign key to the parent ROWID (ON-DELETE-CASCADE) and a row_order Int (0-based Creator row position). A form with several subforms gets one child table per subform; it is not a NoSQL collection. A nested subform inside a subform is not expanded. A grid whose values point at another form is a relation to that form’s table, not a second copy of it.
- time: 1 field (Guest.Door_Opens) — There is no time column. Stored as varchar HH:MM:SS. Range comparisons are generated code.
- url: 1 field (Media_Kit.Portfolio) — URLs routinely exceed varchar 255, which truncates silently. Default storage is text. maxchar of 255 or less stays varchar of that length. Creator also stores link title; a second column is not invented here.
- users: 1 field (Media_Kit.Host) — Stores a user id. Creator org users are not Catalyst app users; people must be invited into the project. A picklist or radio with module = users is this row, not a dropdown.
- video: 1 field (Media_Kit.Walkthrough) — Stratus object key. No video player is generated by the schema step.
