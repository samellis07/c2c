# clean-repo cutover

Copies a repository's full history into a NEW bare repository with every
vendor/agent trailer removed from commit and tag messages. Offline and
read-only on the source: `git fast-export` out, `git fast-import` in. The tool
never pushes, fetches or writes to the source.

```sh
node tools/clean-repo/cutover.mjs <source-repo> <target-dir>
```

## What is stripped

`replace-msg.txt` (also valid as `git filter-repo --replace-msg` input) removes,
anchored to a line start:

- every `Co-Authored-By:` line (agent, bot and human co-author trailers alike);
- `Claude-Session: https://claude.ai/code/session_…` and any other
  `<Vendor>-Session:` trailer;
- `Generated with [Tool](url)` / `Generated with Claude Code` footers, a whole
  line that is only `Generated with Tool` or `Generated by Tool` (one
  capitalized name), and the `🤖 …` footer line;
- a `Signed-off-by:` line that names a `[bot]`.

Prose that merely names a tool mid-sentence is kept. A human `Signed-off-by:`
line that does not name a bot is kept.

## Signatures do not survive

A signature covers the object id and every rewritten commit gets a new id, so
**no commit or tag signature can survive the cutover**. The export runs with
`--signed-commits=strip --signed-tags=strip`:

- signed commits land as ordinary unsigned commits;
- signed annotated tags land as unsigned annotated tags with the same name,
  tagger, date, message and (mapped) target. Apple Git-155 only strips PGP tag
  signatures, so the tool also drops SSH signature blocks from tag messages.

The tool prints how many signed commits and tags it found in the source. Re-sign
in the new repository afterwards if signatures are required.

## Self-checks (target is unusable on a non-zero exit)

| exit | meaning |
| ---- | ------- |
| 3 | bad source, or the target directory is not empty |
| 4 | trailer self-check: a pattern from `VENDOR_TRAILER_CHECKS` (strip.mjs, independent of the rules file) matched a commit or tag message in the target |
| 5 | fidelity: some source/target commit pair differs in tree, mapped parents, author, committer, dates, encoding or expected message; a ref or annotated tag differs; the commit count differs; or the source refs changed during the run |
