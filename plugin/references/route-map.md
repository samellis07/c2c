# Route map: which path creates and verifies each Catalyst resource

Rule: **CLI where the CLI token is proven; MCP where the CLI token lacks the scope or a read; console (guided, user clicks) where neither exists.** Every row has a read-back. MCP names drop the `CatalystbyZoho_` prefix here. All MCP rows are [MCP-LISTED] unless marked otherwise: call `ZohoMCP_getSchema` before the first call, and treat the first live call as a probe.

Sources: public Catalyst docs, zcatalyst-cli 1.27.2/1.28.0 help and source, the Catalyst MCP tool list, and test runs against a Catalyst project.

| Resource | Create / change via | Why this route | Read-back (proof) | Notes |
|---|---|---|---|---|
| **Project** | **Console** (user): Create Project named `c2c-<app-link>`; or `catalyst iac:import -n c2c-<link> iac/c2c-<app>.zip` + browser confirm [CLI] | No `Create_Project` in MCP; CLI create opens the browser; unused `POST /baas/v1/project` is untested [CLI src] | CLI `catalyst --org <org> project:list` [TESTED] (never MCP `Get_Project_By_Id` / `List_All_Projects`: they return project secrets) | 50 projects per account [DOC] |
| Tables, columns, FK | **CLI** (c2c REST with the CLI token): diff-based create-missing | Proven: 3 tables, 32 columns, FK ON-DELETE-CASCADE; re-run printed `created-tables: none` [TESTED] | MCP `List_All_Tables`, `List_All_Columns`; ZCQL join via `Execute_Query` | MCP `Create_Table`/`Create_Column` are a fallback only |
| Table permissions & scopes | **MCP** `Update_Table_Permissions`, `Update_Table_Scopes` | CLI token: `PUT …/permission`, `PUT …/scopes` → 401 `OAUTH_SCOPE_MISMATCH` [TESTED] | MCP `Get_Table_Permissions`, `Get_Table_Scopes` | Or carried in the IaC template (greenfield) |
| Job pool (one per project) | **MCP** `Create_Job_Pool` | CLI token → 401 `OAUTH_SCOPE_MISMATCH` [TESTED] | MCP `List_All_Jobpools` / `Get_Jobpool_By_Id` | Pool names reject `_` [TESTED]; use `c2cpool<h4>` |
| Crons (Job Scheduling) | **CLI** `POST /job_scheduling/cron` (c2c bootstrap) | Works once a pool exists [TESTED] | MCP `List_All_Crons`; CLI GET | Target must be a **Job** function [DOC][TESTED] |
| Jobs (submit) | **CLI** `POST /job_scheduling/job` | Works [TESTED] | job status GET → SUCCESS | |
| Stratus bucket (one per project) | **MCP** `Create_Bucket` | CLI token → 401 even with `Stratus.bucketop.ALL` [TESTED] | MCP `Get_All_Buckets` / `Head_Bucket` | Names are global [DOC]: `c2c-<link>-<h8>` |
| Stratus objects | **CLI** token (`buckets.objects.CREATE`) or MCP `Create_Upload_Signature` / `Generate_Signed_URL` | Object scope held [CLI scopes] — upload [UNVERIFIED] | MCP `Get_All_Objects` / `Head_Object` | Size/multipart limits: [UNVERIFIED] |
| Functions (code) | **CLI** `catalyst deploy --only functions:c2c_api -ni` (c2c deploy) | Proven [TESTED]; MCP has no create/deploy | MCP `List_All_Functions` / `Get_Function`; invoke 401 probe | Deploy **replaces** env vars [TESTED]; use `--function-env` |
| Function env vars | **CLI** via `catalyst-config.json` (merged) | Merge-before-deploy rule | MCP `List_All_Env_Variables` / `Get_Function` | Values typed by the user into a local file |
| API Gateway routes | **MCP** `Configure_API_Gateway_Route`; enable: **CLI** `catalyst apig:enable` [CLI] | No CLI route command | MCP `List_All_API_route`, `Get_API_route` | Needed for Custom APIs |
| Slate app | **CLI** `catalyst slate:link` + `catalyst deploy slate` | Proven after `catalyst.json` `"slate": []` fix [E2E 3c]; MCP get/list only | MCP `List_All_Slate_Apps` / `Get_Slate_App`; `curl -I <App Url>` | App URL must be captured (#76) |
| Authentication enable (hosted + embedded) | **CLI** `POST /authentication/enable?auth_type=hosted\|embedded` body `{"public_signup":false}` | Proven [E2E auth rows 1, 3] | **MCP** `Get_Authentication_Configurations` (CLI read → `OAUTH_SCOPE_MISMATCH` [E2E]) | MCP `Enable_Authentication` is a fallback |
| Auth config update (`url_preference` etc.) | **Console** Authentication → Embedded (no MCP update tool exists) | CLI `PUT` → 401 [E2E row 5] | MCP `Get_Authentication_Configurations` | Else console: Authentication → Embedded |
| Authorized domain (CORS) for the Slate URL | **CLI** `POST /cors-domain {"domain":"<host>","cors":true,"iframe":true}` | Proven [E2E auth rows 2, 4]; iframe on is needed for embedded sign-in | **MCP** `List_All_CORS_Domains` (CLI GET → 401 [E2E]); behavioural: `OPTIONS` preflight returns `Access-Control-Allow-Origin` [E2E] | Repeat POST → `409`; `PUT` → `OAUTH_SCOPE_MISMATCH`: an existing iframe-off entry is a console edit |
| Roles (default App Administrator / App User) | exist by default | — | **MCP** `List_All_Roles` (CLI `GET /role` → 401 [HV H5]) | Role ids differ per project [E2E] |
| Custom roles | **Console** or IaC template (greenfield) | Role create → 401 `AUTHENTICATION_FAILURE` [HV H6]; no MCP Create_Role | MCP `List_All_Roles` | |
| App users (invite) | **CLI** `POST /project-user` (admin add) or MCP `Add_User` | `POST /project-user` worked [HV H7] (with public signup **on**; signup **off**: PROBE FIRST). `/project-user/signup` with signup off → 403 `PUBLIC_SIGNUP_ERROR` [E2E] | CLI `GET /project-user` [E2E] / MCP `List_All_Project_Users` | Always send `redirect_url` = the Slate app URL — the default lands on an unhosted `/app/` path (404). Dev allows 25 users [DOC] |
| Function security rule (auth required) | IaC `SecurityRules` (greenfield) or **console** | No CLI/MCP command [§3a CA-15]; `catalyst deploy` leaves `optional` unless imported | Probe P-401: unauthenticated call → `401 NO_ACCESS` | `is_authenticated` is the only readable signal; probe credential-free — `curl -s -o /dev/null -w '%{http_code}' <function-url>` → `401`; a signed-in session passes the gateway |
| Mail sender | **MCP** `Create_Email_Configuration` (+ `Create_Domain`) then **user** enters the verification code | CLI token has only `email.CREATE` (send) [§3a CA-21] | MCP list email configs (name via `listTools`) → verified | Public-domain sender behaviour **[UNVERIFIED]**; test send needs the user's OK |
| Connections (OAuth to Zoho apps) | **Console** + user consent | No API/MCP [HV `POST /connections` → `INVALID_REQUEST_METHOD`] | CLI `GET /connections` 200 [HV H9]; probe route calling `getConnectionCredentials` | |
| Signals rules | **Console** only, optional | No API/SDK/MCP; locked in Prod [DOC/HV] | Signals probe | c2c dispatches events in-function; Signals is never on the critical path |
| NoSQL table | **Console** only | Create → 401 [HV H8]; no MCP | CLI `GET /nosqltable` 200 | c2c avoids NoSQL (subforms → child tables, #65) |
| Bulk write (data) | **CLI** REST bulk write job (`tables.bulk.CREATE` held) or MCP `Create_Bulk_Write_Job` | Needs a CSV in a Stratus bucket [DOC]; `catalyst ds:import -ni` crashes `reading 'bucket_name'` [HV H19] | `Get_Bulk_Write_Job_Status`; table row counts via `Execute_Query` | **PROBE FIRST**; default data path is `/row` ≤ 200 rows/call [HV, #72] |
| Row inserts (data) | **CLI** `POST /table/<t>/row` JSON array ≤ 200 | Proven by manual load [E2E]; c2c path fixed in #72 | `SELECT COUNT(ROWID)`; per-row `data[]` echo | |
| ZCQL reads | MCP `Execute_Query` or CLI `POST /query` | Both available | — | `*` wildcard, 1-based offset, 300-row cap [HV] |
| Logs | MCP `Get_Logs` | Console logs showed only "Execution started" when handlers logged nothing [E2E U8] | — | |
| IaC export (verify) | **CLI** `catalyst iac:export` (+ `--production`) then `iac:status` | [CLI] | normalized diff | Export holds secrets in clear [HV]: redact in memory, delete the zip |
| Production promotion | **Console** (Deploy to Production, payment method) | No CLI/API for functions/schema [§3a CA-27] | `iac:export --production` diff | CLI has `deploy slate --production`, `ds:import --production` [CLI src] |
| "Start Exploring" | **Guided console line + probe c2c runs** (Cloud Scale, Stratus, SmartBrowz, Slate — only when the app needs the service) | No API opens a service: the console-session `PATCH /service` gets `401 AUTHENTICATION_FAILURE` from the token, no IaC component. First `catalyst deploy slate` → `400` `Please access the Slate service…` while closed | The gate probe answers `200`: `GET …/table`, `GET …/bucket`, `GET /browser360/v1/project/<id>/browser-grid`, `GET /slate/v1/project/<id>/app` | Closed or unrecognised probe → stop before any write, print the one line, re-probe on the re-run (`c2c provision --record <gate>-enable`, deploy `--resume`) |
